理论推导

装置把储能电容的电能转成瞬态冲击，再经导线把形变波送到覆冰层。下面从磁能出发，依次得到轴向力、放电电流、应力波与脱冰判据。上方动画按同一组关系实时演算。

1. 耦合线圈的磁能

驱动线圈与运动电枢可看成一对平面线圈。忽略铁心饱和时，系统磁能为自感项与互感项之和：

Wₘ = ½ L₁ I₁² + ½ L₂ I₂² + M(x) I₁ I₂

L₁、L₂ 随轴向位移 x 变化很弱，互感 M(x) 随气隙增大迅速下降。对角同向通电时互感取最大，气隙越小则梯度越大。

2. 虚功原理 → 轴向力

电流瞬时不变时，广义力等于磁能对广义坐标的偏导。沿轴向取虚位移：

Fₓ = −∂Wₘ/∂x = − I₁ I₂ ∂M/∂x

互感随气隙增大而减小（∂M/∂x 为负），故 Fₓ 把电枢推向导线。线圈 20 匝、层间距尽量小，同时抬高电流与 |∂M/∂x|。气隙缩放取 (4/δ)⁰·⁵⁵。

3. 电容放电电流

储能电容 C = 4000 μF 经晶闸管对线圈放电，回路近似欠阻尼 RLC：

i(t) = (V / ωL) e⁻ᵃᵗ sin(ω t)， ω = √(1/LC − α²)

1500 V 时峰值约 5.96 kA，对应冲击力约 36 kN（4 mm 气隙）。力脉冲相对电流有约 2 ms 机械延迟。

4. 导线应力波

敲击杆与导线刚性锁止，电枢位移瞬时变成导线局部挠度。张力 T、线密度 μ 的档距上，横向扰动以波速

c = √(T/μ)

向两侧传播。形变幅度随距离衰减，脱冰首先发生在敲击点附近。电压可补偿气隙：12 mm 间距时可把充电电压从 500 V 提到 1500 V，以恢复近点位移。

5. 覆冰破坏判据

应变准则

εₚ ≥ εₚmax

积分点塑性应变超过冰的允许上限时，冰层裂成碎片。

冰套分离

Fᵥ + G ≥ Fₐ + F_c

惯性力与重力之和超过黏附力与内聚力时脱落。短时程高幅值载荷更有效。

近点破裂

1500 V · 4 mm · 雨淞 ≈ 90%

雨淞最硬（密度 900–920 kg/m³）。硬雾淞、软雾淞阈值更低，同等冲击下脱落更彻底。

6. 从公式到画面

  1. 选电压、气隙、覆冰 → 得到 Iₚ、Fₚ 与敲击点位移。
  2. 电容充电至目标电压后晶闸管导通，电流按 RLC 振荡。
  3. 电枢在 Fₓ 下加速，挂钩把冲击传入导线。
  4. 应力波沿线传播，超过阈值的冰段开裂并坠落。
